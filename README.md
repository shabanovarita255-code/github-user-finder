# Приложение GitHub User Finder

## Автор
Шабанова Маргарита

## Описание
GUI-приложение с интерфейсом для поиска пользователей на GitHub с использованием GitHub API.

С помощью приложения можно найти пользователей на гитхабе, добавить их в избранное, удалить или полностью очистить избранное.

Приложение хранит данные избранного в локальном файле JSON (favorites.json)

## Использование GitHub API
В приложении используется GitHub REST API:
https://api.github.com/users/{username}

Пример использования:
https://api.github.com/users/octocat

## Функции приложения
- Поиск пользователя на GitHub
- Отображение результата поиска
- Сохранение избранного в локальном файле favorites.json
- Добавление пользователя в избранное
- Удаление выбранного пользователя из избранного
- Полная очистка избранного


## Запуск
```bash
python main.py
```
